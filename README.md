# 📱 Task Management App

A modern and user-friendly Android Task Management App designed to help users organize their day-to-day tasks, manage reminders, build routines, and improve productivity.

## ✨ Features

- 📝 Create, edit, and delete tasks
- ✅ Mark tasks as completed
- ⏰ Set reminders and notifications
- 🔄 Create recurring tasks
- 🏷️ Categories and task priorities
- 📅 Calendar-based task management
- 🔍 Search, filter, and sort tasks
- 📊 Productivity tracking
- 🌙 Light and Dark mode
- 💾 Offline data storage
- 📱 Responsive design for different Android devices

## 🛠️ Technologies

- Kotlin
- Jetpack Compose
- Room Database
- DataStore
- Android Jetpack
- Material Design

## 🎯 Project Goal

The goal of this project is to build a simple, reliable, and efficient productivity application that helps users manage their daily tasks and routines from one place.
